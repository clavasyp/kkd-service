# ККД: тестовое задание Backend (Java)

Сервис проверяет цели сотрудников и ключевые результаты по правилам, хранит результаты в PostgreSQL и отдаёт их через REST API.

Это инструкции для ИИ-ассистента (Claude Code), с которым писалось решение.

## Что главнее

1. `source/Тестовое_задание_Backend_Java.pdf` — задание. При расхождении главнее всего остального.
2. `specs/requirements.md` и `specs/design.md` — спецификация. Код обязан ей соответствовать: это оценивается отдельно.
3. `research/11-solution-plan.md` — план по этапам, раздел 15 содержит результаты проверок запуском.

Папки `source/` и `research/` лежат только локально и в репозиторий не добавляются. Mock API из задания Frontend — подсказка, а не требование.

## Команды

Команды для Git Bash и Linux. JDK и Maven локально не нужны.

```bash
docker compose up -d --build                             # база, миграции, сервис
docker build --target test --progress=plain .            # тесты
docker build --target test --progress=plain --build-arg RERUN=$(date +%s) .  # тесты заново, кэш Maven цел
docker compose run --rm migrate rollback --tag=v0-empty  # откат всего
docker compose run --rm migrate update                   # повторный накат
docker compose down -v                                   # сброс базы, это не откат
bash scripts/check-chain.sh                              # сквозная проверка, сбрасывает базу в начале и при успехе
```

После правки файлов в `db/changelog` нужна пересборка: `docker compose build migrate`.

## Правила

- Спецификация правится в том же коммите, что и код. README и `specs/` не должны расходиться с кодом.
- В `ru.kkd.domain` нет Spring, SQL и HTTP. Проверка: `grep -rE 'org\.springframework|java\.sql' src/main/java/ru/kkd/domain` ничего не находит.
- `LocalDate.now()` в `src/main` не используется: дата всегда берётся из снимка прогона.
- Веса и метрики считаются в `BigDecimal`, сравнение через `compareTo`.
- Контрольные числа стартовых данных живут только в README. Ожидание правится только после разбора расхождения.
- У каждого changeset есть откат. В текстах данных нет символа `;`: Liquibase делит SQL по нему.
- Версия Spring Boot только 3.5.16. Документацию открывать по адресам с `/3.5/`: по умолчанию открывается 4.x.
- Порт базы снаружи 15432: на этой машине 5432 занят локальным PostgreSQL.
- Все файлы с окончаниями LF.

## Как ведём работу

- Этапы идут по порядку из раздела 10 плана. Этап закрыт, когда выполнена его проверка из плана и результат подтверждён запуском.
- Перед коммитом логики: тесты в Docker и ревью изменений (`/code-review`).
- Работа идёт в ветке `feature/kkd-service` и вливается в `main`.
- Что считается фактом: только то, что проверено запуском или прямо написано в задании. Остальное называем решением или предположением.
